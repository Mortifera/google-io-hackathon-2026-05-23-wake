# worlds/notion — the Notion world (L5)

The static graph the kernel runs cascades against. The focal scenario is
**Microsoft acquiring Notion** (plus four adjacent shocks — see Seeds). Produced
here as JSON, consumed by `@wake/kernel` via `loadWorld()`, validated against
`WorldSchema` in `@wake/contracts`.

## Files

| File | What it is |
|------|------------|
| `world.json` | **The deliverable.** ~200-node tiered world. Generated; committed. |
| `mini.json` | Shared 8-node toy fixture (owned upstream — **do not edit**). |
| `build.ts` | Generator: assembles nodes/edges/seeds, validates, writes `world.json`. |
| `dossiers.t1.ts` | Curated Tier-1 dossiers (composites from public sources). |
| `dossiers.bulk.json` | Tier-2/3 dossiers generated by Gemini Flash; override layer. |
| `gen-dossiers.ts` | Calls `gemini-3.5-flash` to (re)generate `dossiers.bulk.json`. |
| `validate.ts` | Schema + integrity checks (CLI + shared by the test). |
| `world.test.ts` | Vitest: loads via `loadWorld()`, runs `checkWorld()`. |

## Regenerate / validate

```bash
pnpm exec tsx worlds/notion/build.ts        # rebuild world.json (offline)
pnpm exec tsx worlds/notion/validate.ts     # schema + integrity check
pnpm exec vitest run --config worlds/notion/vitest.config.ts
# optional, costs a few cents of live Flash — refresh the bulk dossiers:
pnpm exec tsx worlds/notion/gen-dossiers.ts && pnpm exec tsx worlds/notion/build.ts
```

`build.ts` works offline: if `dossiers.bulk.json` is absent it falls back to the
first-pass dossiers inlined in `build.ts`. Tier-1 is always the curated text in
`dossiers.t1.ts`.

## Tiering (fidelity is distributed, not uniform)

- **Tier 1 (~40):** named leadership, competitors, journalists/analysts,
  influencers/VCs — full ~200-token dossiers (voice, recent public positions,
  relationships, decision patterns, biases). Each leads with its **disposition**
  toward the acquisition. Curated hardest; the audience judges quality here.
- **Tier 2 (~74):** archetype cohorts (Notion middle management, IC teams,
  customer cohorts by use-case, communities, influencer clusters, Microsoft
  internal orgs, investors, regulators, dev ecosystem, channels). Shared-archetype
  dossiers; state diverges per instance.
- **Tier 3 (~93):** aggregates / count nodes (regional user masses, free-tier
  sub-segments, enterprise verticals, competitor user bases, follower/reader
  masses, etc.) with averaged sentiment.

Dossiers are **composites from public sources**; uncertainty is marked
("reportedly / likely / inferred") and no quotes are fabricated (AGENTS.md §4).
The Tier-1 set is current as of May 2026 (e.g. Notion ~$500M ARR / ~$11B; Coda
now inside Superhuman; Asana under Dan Rogers; Rajesh Jha's retirement and Jeff
Teper's Loop succession).

## Edge vocabulary

`character` is a free string, but **load-bearing (`llmMediated: true`) edges use
only the keys L4 builds its transforms around** — the 6 `EDGE_ARCHETYPES`
(`journalist->audience`, `employee->manager`, `customer->cohort`,
`competitor->strategy`, `platform-amplification`, `friend->friend`) plus the
three already in `mini.json` (`company->journalist`, `internal-leadership`,
`leadership->report`). Light, deterministic edges (`llmMediated: false`) may use
any descriptive character (`following`, `membership`, `analyst->market`,
`investor->company`, `regulator->company`, `competitor->customers`), which L4
handles with cheap weight-driven rules. `validate.ts` enforces this.

The spine is curated (the acquisition path, internal leadership rings, the
manager funnel, journalist→audience); the long-tail fan-out to masses is light.

## Seeds (the on-stage action menu)

`acquisition` · `free-tier-removal` · `ceo-steps-down` · `open-source` ·
`engineer-idea`. The 8 `mini.json` node ids are preserved so existing fixtures
and the engineer-idea / acquisition demos resolve against this world.
